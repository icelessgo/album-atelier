# Print-file output contract

Proofing, design approval, payment and submission to a lab are distinct actions.
Generation or client approval never submits an order to a supplier.

## Saal Professional Line

Profiles include 30×30 square, 30×21 landscape and 22×30 portrait. The prototype
supports the implemented standard matte Professional Line construction with
acrylic/white leatherette and its measured page/cover constraints. Its export
produces a cover PDF and an interior PDF, plus the available production/approval
records. Confirm the exact current supplier configuration before ordering.

In the original private workflow, a combined cover/interior PDF upload was accepted
by Saal's importer. A physical copy has not yet been validated. This is evidence of
that import test, not certification for all lab formats, materials or future tools.

## Graphistudio

GoBook and EDGE presets provide the implemented interior layout/export geometry
and companion specifications. Do not assume this is a complete supplier order
package: cover/printed-edge artwork and any unsupported companion output still
need the supplier's own design/order process and an independent check. The new
neutral cover illustration is a visual aid, not production artwork.

## Approval and original-image checks

The workflow records the offered product and price, format, layout, crops and
source-image hashes. Changing an approved source, crop, layout or shape requires
the matching fresh review/approval. Full-resolution exports use isolated input
copies and must match the approved sources. Screen previews are not print files.

Retain the production files, checksums and approval evidence privately. Never
publish them in the source repository or use the synthetic demo as a lab sample.
